# 采用模块化单体与上海单活动运行时

Rhea V1 使用 TypeScript 模块化单体，在一个 monorepo 中维护领域模块；每个模块拥有自己的表和迁移，跨模块只能使用公开接口或领域事件。`app-api`、`ai-worker`、`domain-worker` 和 `safety-worker` 是独立进程，但共同部署在一台上海活动 ECS 上。PostgreSQL、Redis、对象存储和密钥使用上海托管服务，不与应用服务器共机。该方案用应用层单点和短时停服换取 MVP 的较低部署复杂度；只有容量、恢复目标、故障隔离、属地隔离或团队所有权出现实证压力时才增加副本或拆成微服务。

应用实例必须无状态并可由版本化镜像重新创建。V1 以 RPO 不超过 15 分钟、RTO 不超过 4 小时和季度恢复演练约束这一取舍，不宣称应用层高可用。
