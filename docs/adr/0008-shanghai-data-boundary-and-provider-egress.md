# 采用上海数据边界与供应商出站白名单

Rhea 首发基础设施以阿里云上海为默认实施基线：活动 ECS、RDS PostgreSQL、Tair/Redis、OSS 和 KMS 位于上海。原图只发送到已签署的上海 OCR；生成式 AI 可以使用中国大陆其他地域，但只接收去标识后的确认文本和确有必要的最小裁剪。阿里云 IDaaS CIAM、上海 OCR 和百炼北京地域只是首选候选，不能绕过合同与能力版本签署。

生产环境对网络出站默认拒绝，只允许数据流台账中登记的中国大陆端点。每个供应商必须证明处理地域、保留期限、不用于训练、子处理者、支持访问、删除 SLA 和事件通报；不满足时相应能力保持不可用。海外分析、客服、崩溃追踪、备份、推送和模型服务默认关闭。公开上线还以完成适用 APP/ICP、教育审批、儿童信息、AI 标识及算法/模型备案专业审核为前置门槛。
